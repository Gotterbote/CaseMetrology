# V3 Protocol Amendment 001

Date: 2026-09-11

Status: PRE-ACQUISITION

No V3 formal measurement data had been collected when this amendment was issued.

## Change

The planned 60-specimen manual stability-check round is removed from the V3 formal validation procedure.

The accepted V1 three-round manual-reference means remain the frozen manual ground truth for V3.

## Rationale

V3 is intended to provide a directly paired V1-to-V3 comparison using the same retained 60 specimens and the same accepted manual-reference values. Repeating the manual-reference study is not required for the primary V3 research question and could introduce an unnecessary additional source of variation.

## Unchanged Elements

This amendment does not change:

- the frozen 60-specimen formal cohort;
- V3 hardware or fixture configuration;
- controlled specimen roll orientation;
- existing accepted calibration;
- Endface Hybrid as the primary estimator;
- PCA as the V1 comparator;
- Geometry as the secondary estimator;
- the three frozen randomized V3 CV run orders;
- the prospective V3 performance criteria;
- the frozen software/configuration hashes.

The next formal activity is V3 CV acquisition beginning with V3-CV-S001.
