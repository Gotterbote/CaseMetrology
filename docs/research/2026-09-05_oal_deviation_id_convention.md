# OAL Deviation ID Convention

Date: 2026-09-05  
Operator: Timmy D. Bell  
Scope: Formal M.S. OAL validation only.

Formal protocol deviations shall use sequential identifiers:

`DEV-001`, `DEV-002`, `DEV-003`, ...

Each new deviation receives the next unused identifier.

Deviation identifiers shall not be reused or renumbered.

This convention supplements the existing formal OAL protocol-deviation and
data-disposition policy. All previously frozen status, replacement, and
disposition rules remain unchanged.
