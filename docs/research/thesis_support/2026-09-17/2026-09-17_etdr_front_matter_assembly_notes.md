## Front-matter sequence

For the master's thesis, assemble the document using the current K-State master's thesis Word template. The required core front matter is:

1. Title page
2. Copyright page, optional but recommended by the K-State template
3. Abstract
4. Table of Contents
5. List of Tables, because the thesis contains tables
6. List of Figures only if figures are ultimately included
7. Acknowledgements, optional
8. Dedication, optional
9. Preface, optional

Chapter 1 begins Arabic page numbering at page 1.

## Abstract controls

The abstract in this package is deliberately kept below 500 words to satisfy the more conservative Graduate Handbook requirement. It contains no citations and avoids mathematical inequality signs, plus-minus notation, Greek letters, and other special mathematical symbols.

Do not add citations to the abstract.

## Tables and figures

The current manuscript contains 14 labeled tables and no labeled figures.

K-State requires captions for each table and figure, and the Word template generates the corresponding lists from Word caption fields. When the manuscript is moved into the template, table captions should be inserted using Word's caption feature rather than left only as manually typed bold labels.

No figure should be added solely to satisfy formatting expectations. A List of Figures is needed only if figures are included.

## Formatting controls from current K-State guidance

- One-inch margins are standard; the left margin may be one and one-half inches for personal binding.
- Ten- or twelve-point legible font is preferred and must be consistent.
- Double spacing is preferred; one-and-one-half spacing is acceptable.
- Bibliographic entries may be single spaced with a blank line between entries.
- Page numbers must be centered or right justified.
- Preliminary-page numbering and section breaks should be handled by the K-State template.
- Table of Contents and lists should be generated and updated automatically rather than typed manually.
