# OAL Manual Session ID Convention

Date: 2026-09-05  
Operator: Timmy D. Bell  
Scope: Formal M.S. OAL validation only.

Formal manual-measurement sessions shall use sequential identifiers:

`MAN-S001`, `MAN-S002`, `MAN-S003`, ...

Each new continuous manual-measurement session receives the next unused identifier.

Session identifiers shall not be reused or renumbered.

The designated manual-reference instrument remains Mitutoyo 500-196-30,
serial B24254849, as established by the September 3, 2026 reference-system amendment.
